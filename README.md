# Hi, I'm Badr Rachidi Alaoui

Information Systems & Big Data engineering student interested in
data engineering, applied machine learning, and MLOps.

I build projects that connect data ingestion and validation to
analytics, model serving, monitoring, and dashboards.

## Featured projects

### Industrial Predictive Maintenance

An educational MLOps platform that estimates engine remaining useful
life using NASA C-MAPSS sensor histories.

- Engine-level evaluation and leakage-safe feature engineering.
- MLflow experiment tracking and model registration.
- FastAPI predictions with SHAP explanations.
- Airflow orchestration, monitoring, and a Streamlit dashboard.
- Automated tests and Docker image checks through GitHub Actions.

[Explore the project](https://github.com/just-badr00/industrial-predictive-maintenance)

### Sanlam Insurance Data Pipeline

An insurance analytics platform developed during an introductory
internship at Sanlam Maroc, using synthetic data.

- Oracle ingestion with per-table timestamp watermarks.
- Raw, Silver, and Gold data layers in MinIO.
- PySpark transformations and data-quality checks.
- Airflow orchestration and Tableau reporting.

[Explore the project](https://github.com/just-badr00/sanlam-insurance-data-pipeline)
